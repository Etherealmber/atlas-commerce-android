# Atlas Commerce — Android

Native Android companion for [Etherealmber/atlas-commerce](https://github.com/Etherealmber/atlas-commerce).

## Stack
- Kotlin + Jetpack Compose + Material 3
- Hilt, Retrofit/OkHttp, Room
- API: `https://stock.afmarbre.com`

## Build
1. Open in Android Studio (Ladybug / AGP 8.7+).
2. Copy `app/google-services.json.example` → `app/google-services.json` if using Firebase.
3. Sync Gradle and run (minSdk 28).

## Version
`1.0.4` (versionCode 104)

Transfer target: `Etherealmber/atlas-commerce-android` when org app access is granted.
